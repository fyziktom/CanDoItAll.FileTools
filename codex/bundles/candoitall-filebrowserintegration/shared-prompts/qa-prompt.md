# QA Prompt

Validate the selected subbundle against the literal raw request and its semantic invariants, not only file existence or passing counts.

Check dependency direction, partial-class policy, direct unit seams, negative cases, source hashes/assertions, anti-stub output, command transcripts, and downstream smoke. For UI, use a real headed browser: maximized first, inspect the screenshot, then dialog/floating/low-height/narrow widths. Open menus/overlays and verify readability, clipping, lateral overflow, layering, scroll ownership, hierarchy, spacing, selection, and interaction affordances. Exercise file activation and host action routing rather than static markup only.

Fail the gate if the shallow implementation still passes, a manifest path is missing, FileTools references main/optional concrete dependencies incorrectly, disabled cache remains stale, save marks clean before successful host completion, or screenshots are visually unacceptable. Mark deferred CanDoItAll production rows Partially solved with their exact future phase rather than claiming they shipped.
